# Because It's Too Easy

Survival was too easy.

A small Fabric mod that puts the pressure back into survival:

- 🥩 Food spoils over time
- 🍂 Four seasons (9 days each), with weather and temperature shifting by season
- 💧 Thirst system
- 🍽️ More realistic hunger metabolism

## Requirements

Minecraft 26.2 · Fabric Loader ≥0.19.3 · Fabric API
